# Home

## The Central Thread

**[[Ms. Lauryn Hill]]** — *To Zion* (feat. Carlos Santana, 1998) is the seed of this entire exploration.

That response led in three directions:
- **Neo-soul lineage** → [[Neo-Soul]]
- **Flamenco / nylon-string guitar world** → [[Flamenco]]
- **British/Irish folk-soul** → [[British Folk]] / [[Celtic Soul  Irish Folk-Soul]]

## Sections

- `Artists/` folder — every artist encountered
- `Genres/` folder — genre/tradition overviews
- `Concepts/` folder — recurring ideas (saudade, duende, nylon-string warmth, controlled chaos)
- `Playlists/` folder — built playlists with Spotify links
- [[Next Directions]] — flagged listens, not yet done
